# Halo Flashpoint Curator

A helper for a custom game mode for [Halo Flashpoint](https://haloflashpoint.manticgames.com/). Not endorsed or affialted with Mantic. Just a helper for a fan made mode.

Rules for this mode can be found [here](https://docs.google.com/document/d/1u_2p-X96LQhyjqh5hMqCkAuZm8qABIQTsVKCrYofU78/edit?usp=sharing)

# Run on the web
https://kingofmongeese.github.io/Flashpoint-Curator/

# Running Local

```cargo run --release```

# Running in WASM

```cargo install --locked trunk```

```trunk serve --release --address 0.0.0.0```

Then connect on a device.
